# PixelForge

A responsive, coursework-ready static website for PixelForge, a fictional video game company based in Chichester, UK.

## Pages

- `index.html` - Home page and featured games
- `games.html` - Four-game catalogue
- `about.html` - Company mission and values
- `contact.html` - Studio contact details and contact form

All pages share `styles.css` and local artwork in `assets/`. Open `index.html` in a browser to explore the site.
